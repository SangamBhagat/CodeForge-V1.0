Marks file format guidance

  • Upload an Excel file with exactly three columns: BITS ID, Course, and Total Marks.
  • Total Marks must be whole numbers. Round fractional values to the nearest integer (for example, 80.2 → 80).
  • Leave out students who did not appear for the trimester-end examination and should receive an NC grade.
  • Grade only students who appeared for the examination.
  • Identical entries for the same BITS ID and course count once. Correct conflicting marks before grading.
