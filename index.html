Marks file format guidance

The uploaded Excel file should contain exactly three columns: BITS ID, Course, and Total Marks.

Total Marks should be whole numbers. Round fractional values to the nearest integer (for example, 80.2 → 80).

Students who did not appear for the trimester-end examination and are to be awarded an NC grade should not be included in the file.

This console is intended for grading only students who appeared for the examination.

Repeated entries for the same BITS ID and course with the same marks are counted once. Conflicting marks must be corrected before grading.
